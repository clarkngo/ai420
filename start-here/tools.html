Two tools, two jobs

Google Antigravity is the coding agent you work with: you give it a task, review its plan, and check what it builds. Google ADK (Agent Development Kit) is the framework you build agents in. Antigravity is itself an agent, so the first thing you'll do in Module 1 is watch one work before you build your own.

💻

Install on your computer

About 30 minutes, once

You need a Mac, Windows or Linux computer you can install software on. Can't install? Use Codespaces instead and skip this section.

  1. Google Antigravity. Download it from antigravity.google and sign in with a personal Google account. The free Individual plan is enough for this course. Its usage limit resets weekly, so don't leave a whole HOS for the last night.
  2. Python 3.11 or newer from python.org. On Windows, tick Add python.exe to PATH in the installer.
  3. Git from git-scm.com (macOS: run git --version once and accept the prompt to install the developer tools).
  4. Google Chrome, if you don't have it. Antigravity's browser agent drives Chrome.

Check it in Antigravity's terminal (Terminal → New Terminal):

python3 --version    # Windows: py --version
git --version
▶️

First run: one HOS repo, start to finish

Every HOS starts with these same six steps. The repo URL comes from the HOS invite link in each module.

  1. Clone your repo. In Antigravity: File → Open Folder on an empty folder for the course, then in the terminal: git clone <your repo URL>, and open the cloned folder.
  2. Make a virtual environment and install. 
    python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt  # includes google-adk
  3. Add your key. Copy .env.example to .env and paste your Gemini key after GOOGLE_API_KEY=. Leave GOOGLE_GENAI_USE_VERTEXAI=FALSE as it is.
  4. Start the developer UI. From the repo's top folder: adk web, then open http://localhost:8000 in your browser, pick the agent, and say hello.
  5. Look at the Events tab. Every model call and tool call is listed there. You'll use it in every HOS.
  6. Commit and push when you finish a stage: git add -A && git commit -m "Stage 1" && git push. Your NOTES.md and code in the repo are what gets graded.

When the agent is about to run a command

Antigravity can run terminal commands, edit files and open a browser on your computer. Keep its default of asking you before it runs terminal commands, and read each one before you approve it. Never let it put your API key in a file other than .env.

☁️

No install? Use Codespaces

On a Chromebook, a locked work laptop, or when Antigravity won't install, open the same repo in GitHub Codespaces (Code → Codespaces → Create codespace on main). Everything is graded the same way.

  • The coding assistant there is GitHub Copilot (free for verified students) instead of Antigravity. In Module 1's Antigravity warm-up, watch the demo video and answer from it.
  • The Codespace installs the requirements for you. Add your key to .env as above.
  • Start the UI with adk web --allow_origins "*". Plain adk web returns 403 errors in Codespaces. Open the forwarded port 8000 when VS Code offers it.
  • Stop the Codespace when you finish (Codespaces → Stop current codespace) to save your free monthly hours.

Universal tooling

Read before Week 1

These tools show up in every HOS of this course, not just one. Get comfortable with them once, here.

The setup path you'll repeat at the start of every HOS.

Google Antigravity: an agent-first IDE

An editor with a coding agent built in. You describe a task in the Agent panel; with /plan it first writes an Implementation Plan and a task list for you to review, then edits files, runs commands, and ends with a walkthrough of what it did. These reviewable outputs are called artifacts.

Why it matters: you are responsible for everything it builds. Read the plan before you approve it, and comment on it when it's wrong. That habit is the Evaluate stage of every HOS.

Google ADK (Agent Development Kit)

Google's open-source Python framework for agents. An agent is a root_agent = Agent(name=..., model=..., instruction=..., tools=[...]) in agent.py; ADK runs the loop of model calls and tool calls for you and records each step as an event.

Why it matters: ADK is what this course teaches. Antigravity writes code fast, but the HOS ask you to explain, test and extend the ADK parts yourself.

adk web, adk run and adk eval

adk web starts a local developer UI with a chat window and the Events and Trace views. adk run my_agent chats in the terminal. adk eval runs a saved set of test conversations (Module 4).

Why it matters: run adk web from the folder above your agent folders, or it won't find them. That is the most common Week 1 snag.

Terminal / command line

A text-based way to run programs and commands. This course uses it constantly: starting adk web, installing packages, running scripts. Opening a new terminal tab starts you back at the folder you opened, so cd into the folder you need first, every time.

Python virtual environment (.venv)

A private copy of Python and its packages for one project. python3 -m venv .venv creates it; activating it switches your terminal to use it. You'll see (.venv) at the start of the prompt.

Why it matters: "adk: command not found" almost always means the venv isn't active in that terminal tab.

Environment variables & .env files

A .env file holds settings and secrets such as GOOGLE_API_KEY=... as plain NAME=value lines, outside your code. ADK reads the .env in the agent's folder when it starts.

Why it matters: every repo's .gitignore already excludes .env, so your key never reaches GitHub. Treat the key like a password: never paste it into a chat, a prompt, or a screenshot.

Git and your Classroom repo

Each HOS and AC has its own GitHub repo, created from the invite link. You clone it, work locally, then commit and push. The pushed repo, with your NOTES.md, is your submission.

Working with a coding agent

The first stage of each HOS (Create/Scaffold) is deliberately agent-driven: Antigravity builds with you. The rest of the HOS proves, in writing and by hand, that you understand what was built.

Why it matters: getting the agent-built code running is only 20% of each HOS grade (Create). The other 80% is whether you can evaluate it, explain it, and extend it without AI help.
Quick self-check before you continue
  • Does adk web open in your browser, and can you find the Events tab?
  • Do you know where your Gemini API key is stored, and why it's not inside a .py file?
  • Do you know which part of each HOS is done with Antigravity, and which parts you must do and explain yourself?
