GitHub

First needed: HOS 1Free — no credit card

What it's for: your own repo for each HOS and Application Challenge, created from the invite link in each module. If you can't install software on your computer, GitHub Codespaces gives you the same setup in the browser.

  1. Go to github.com and click Sign up (top right).
  2. Enter an email, create a password, and pick a username. Use something professional: this account is worth keeping for internships and job applications.
  3. Verify your email when GitHub sends the confirmation.
  4. Optional but useful: apply for the free GitHub Student Developer Pack, which adds Copilot and more Codespaces hours.
Already have a GitHub account from another course or personal projects? Use that one. One consistent GitHub profile is more useful to you later than several scattered ones.

You'll know it worked when…

  • You can sign in at github.com and git clone a repo in Antigravity's terminal. The first push asks you to sign in to GitHub in the browser.
🚀

Google Antigravity

First needed: HOS 1Free Individual plan

What it's for: the agent-first editor you build with all term. Its coding agent plans, edits and tests with you; you review and decide.

  1. Download it from antigravity.google for macOS, Windows or Linux and install it.
  2. Open it and choose Continue with Google. Use a personal Google account (a Gmail address). School and work Google accounts may be refused.
  3. Accept the default settings, including the one that asks before the agent runs terminal commands.
Usage limits. The free plan has a weekly limit on agent requests. Start each HOS early in its first week. If you hit the limit, the HOS steps still work by hand or with Copilot, and nothing is graded on how much the agent did.

You'll know it worked when…

  • The Agent panel answers a question about an open folder, for example "What files are in this folder?"
🔑

Google AI Studio: Gemini API key

First needed: HOS 1Free — no credit card

What it's for: the key that lets your ADK agents call Gemini. It is separate from Antigravity's own sign-in: Antigravity's agent runs on Google's plan, your agents run on your key. You get it once and reuse it for every HOS.

  1. Go to aistudio.google.com/apikey and sign in with the same personal Google account.
  2. Click Create API key.
  3. Copy the long string it gives you. It starts with something like AIza....
  4. Paste it into your project's .env file: 
    GOOGLE_GENAI_USE_VERTEXAI=FALSE
GOOGLE_API_KEY=AIzaSyD-your-real-key-goes-right-here
Treat this like a password. Never paste it into a file you commit, a chat, an Antigravity prompt, or a screenshot. That's exactly why it lives in .env and not in your code. The free tier needs no billing account; if a call fails with a rate-limit error, wait a minute and try again.

You'll know it worked when…

  • Your agent answers in adk web. A missing or wrong key shows an error in the chat panel on the first message.
🧩

Putting it all together

Each HOS repo has its own .env, copied from .env.example. It holds the same two lines all term:

GOOGLE_GENAI_USE_VERTEXAI=FALSE
GOOGLE_API_KEY=AIzaSyD-your-real-key-goes-right-here

This file is excluded from Git by each repo's .gitignore. It stays on your computer (or your Codespace) and is never committed.
