Memory and planning

Memory = the session

ADK sends every earlier event back to the model on each call.

The model itself remembers nothing.

Planning = invisible here

One step at a time, inside each model call.

Common mistakes

Three to avoid

1

A tool with no docstring

The model sees only a name and argument types, so it guesses when to call it.

2

Running adk web from the wrong folder

Run it from the folder above your agent's folder, or the agent list is empty.

3

No step budget

Every call costs tokens. Set one: RunConfig(max_llm_calls=...)
