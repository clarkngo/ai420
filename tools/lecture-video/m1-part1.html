The real lesson
The single call's right answers and wrong answers look identical.
An agent shows how it got there, so every step can be checked.

Common mistakes

Three to avoid

1

Calling anything with a model in it an agent

One call is inference, however clever the prompt. The loop makes the agent.

2

Treating a right answer as proof

Ask how the answer was reached.

3

Reaching for an agent first

More calls, tokens and time. Many tasks are better as one call or a fixed script.
