Common mistakes

Two to avoid

1

Plain adk web in Codespaces

It returns 403 Forbidden there. Use adk web --allow_origins "*". On your own computer, plain adk web is fine.

2

Picking a pattern by fashion

Plan-and-execute isn't "more advanced" than ReAct. It suits different tasks, so measure both.
